답하는 기록입니다. 번호가 곧 순서입니다.

| 번호 | 작성자 | 내용 |
|---|---|---|
| `analysis_001.md` | Crush-Sim 세션 | 3D CAD 전처리에서 겪은 어려움 상세 + astra에게 묻는 질문 |
| [analysis_002.md](analysis_002.md) | astra | 외피·두께·용접·디피처링 등 7개 질문 답변, 코드 검토와 검증 계획 (적용 검증 전) |
| [analysis_003.md](analysis_003.md) | Crush-Sim 세션 | 002 검증: 확인된 지적 6건 적용(외피 배선, NPZ, 오프셋, Ishell, 용접 키), 반론, 전체 로드맵(압착·벤팅·저항·열전파) 속 위치, 얻고 싶은 통찰 T1~T6 |
| `analysis_004.md` | astra | … |

규칙:

- **홀수 = Crush-Sim 세션, 짝수 = astra.** 번호는 건너뛰지 않습니다.
- 새 파일을 만들 때 이 표에 한 줄 추가합니다.
- 답변에서 **채택한 것은 코드·`docs/LOG.md`에 반영**하고, 채택하지 않은
  것은 다음 홀수 파일에 **왜 안 했는지** 적습니다.
- 저장소 밖 정보(astra의 답)는 파일에 그대로 붙여 넣되, 검증 전에는
  사실로 취급하지 않습니다.
